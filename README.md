# 2分セキュリティ診断

9つの問いに答えると、パスワードやメールアドレスの守り方で、どこから手をつければいいかが分かるページです。

- 診断：https://mikiyoko.github.io/security-checkup/
- 事業者の方へ「その個人情報、本当に要りますか」：https://mikiyoko.github.io/security-checkup/business.html

## なぜ作ったか

サービスの側から漏れた情報は、個人では防げません。でも、漏れたIDやパスワードを足がかりに、ほかのアカウントまで次々に乗っ取られるのは、自分で止められます。そのための入口として作りました。

事業者向けのページは、会員登録の項目を見直すための考え方と、項目ごとの問いをまとめたものです。

## 答えの扱い

- いまは、答えをこのページの中（ブラウザ）だけで計算しています。どこにも送りません
- 今後、答えを集計して「診断した人のうち◯%」を出す予定です。その場合も、名前・メールアドレス・地域・IPアドレスは保存しません。始めるときは、このページとREADMEに、何を保存するかを書きます
