# 2分セキュリティ診断

9つの問いに答えると、パスワードやメールアドレスの守り方で、どこから手をつければいいかが分かるページです。

- 診断：https://mikiyoko.github.io/security-checkup/
- 事業者の方へ「その個人情報、本当に要りますか」：https://mikiyoko.github.io/security-checkup/business.html

## なぜ作ったか

サービスの側から漏れた情報は、個人では防げません。でも、漏れたIDやパスワードを足がかりに、ほかのアカウントまで次々に乗っ取られる危険は、自分の対策で大きく減らせます。そのための入口として作りました。

事業者向けのページは、会員登録の項目を見直すための考え方と、項目ごとの問いをまとめたものです。

## 答えの扱い

- 診断の結果を出したときに、答えを1回だけ送って集計します（「おすすめの対策を先に見る」から入った場合は送りません）
- 保存するのは、答えた日（日本時間の日付だけ）・9問の答え（何番目の選択肢か）・年代（「答えない」を含む）だけです
- 名前・メールアドレス・地域・IPアドレス・ブラウザの情報は保存しません。受け取り口では、リクエストの記録（ログ）も残さない設定にしています
- 受け取り口はCloudflare Workers、保存先はCloudflare D1です。コードは `worker/` にあります。仕組み上、Cloudflare側には通信の記録が一時的に残ります
